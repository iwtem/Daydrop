# 知时 · Daydrop

轻如水滴的 macOS 原生极简日历应用，常驻顶部菜单栏、不在 Dock 占位，支持独立放大窗口、macOS 桌面小组件（WidgetKit）与中英文双语，专注日期、中国法定节假日、二十四节气与农历展示。

## 核心特性

- **菜单栏常驻，零 Dock 占用**：配置 `LSUIElement = YES`，平时仅显示极简日历图标，遇到节日或二十四节气自动在图标旁显示当天名称（支持在设置中自由切换样式）。
- **可放大独立窗口**：支持一键展开为可自由缩放的独立桌面窗口，提供**月视图（配右侧今日日签、近期提醒与本月节气）**与**年视图**切换；跨月浏览时柔和标记与今日同日号日期。
- **macOS 桌面小组件（WidgetKit）**：提供**小号（今日日签）**、**中号（今日日签 + 紧凑月历）**、**大号（完整桌面月历）**三种尺寸，完整适配全彩与 macOS 透明玻璃（Vibrant）模式，每日零点自动刷新。
- **纯离线精准历法引擎**：
  - **农历**：基于原生 `Calendar(identifier: .chinese)`，支持干支纪年、生肖、闰月与传统节日（除夕、春节、元宵、端午、中秋等）。
  - **二十四节气**：内置高精度天文太阳黄经算法（北京时间 UTC+8），离线精确计算任意年份全部 24 节气。
  - **法定节假日与调休**：内置国务院官方放假与调休安排（2024–2027，已按国办发明电〔2026〕10号更新 2027 全年安排），并支持后台静默拉取 `holiday-cn` 静态源热更新未来年份，支持「休 / 班」角标与下一假期倒计时。
- **5 套年轻亮色主题皮肤**：内置「蜜桃苏打 / 薄荷珊瑚 / 阳光柑橘 / 电光晴空 / 鸢尾莓粉」五套纯色扁平主题，主应用与桌面小组件实时联动切换。
- **中英文双语**：默认跟随系统语言，同时支持在偏好设置中实时切换简体中文 / English，并自动同步至桌面小组件。

## 快速运行

1. 使用 Xcode 打开 [`Daydrop.xcodeproj`](Daydrop.xcodeproj)（要求 macOS 14.0+）。
2. 选择 `Daydrop` scheme，按 `⌘R` 编译运行（默认已配置本地签名，无需开发者账号即可运行）。
3. 运行后顶部菜单栏会出现「知时」图标；在桌面空白处右键选择 **「编辑小组件」**，搜索 **「知时」** 或 **「Daydrop」** 即可添加桌面小组件。

## 项目结构

```text
Daydrop/
├── Daydrop.xcodeproj/        # Xcode 工程（Daydrop / DaydropWidget / DaydropTests）
├── Shared/                   # 主应用与小组件共享核心层
│   ├── CalendarEngine/       # 二十四节气天文算法、农历引擎、月历网格生成
│   ├── HolidayData/          # 法定节假日与调休数据（holidays_cn.json）
│   ├── Localization/         # 中英文双语引擎（L10n）
│   ├── Theme/                # 「蜜桃苏打」主题色系（适配浅色/深色模式）
│   └── Settings/             # 共享偏好配置（主应用与小组件实时同步）
├── Daydrop/                  # macOS 主应用（菜单栏弹窗 + 独立放大窗口 + 偏好设置）
├── DaydropWidget/            # WidgetKit 桌面小组件（Small / Medium / Large）
├── DaydropTests/             # 历法、节气、节假日、双语单元测试
└── scripts/                  # 矢量图标生成脚本与工程生成脚本
```
